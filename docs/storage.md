# Storage and Filesystems on SUNBIRD2

!!! important

    SUNBIRD2's filesystems are intended
    for holding data while you are working on them using HPC services.
    They are not designed for long-term data retention,
    and are not automatically backed up.
    You should retain external copies of any essential research data,
    and should have a Data Management Plan detailing how these are curated.

SUNBIRD2 has around a petabyte of high-speed parallel storage.
The following locations are available:

- `/pixhome/USERNAME`:
  This is your home directory.
  It should be used for retaining
  any software or data you plan to use long-term on SUNBIRD2.
  By default it has a quota of 200GB or 1 million files.
- `/scratch/PROJECT`:
  Each project you're a member of has a shared scratch directory.
  This should be used for larger etransient data,
  staging onto the system for analysis,
  generated by a job and held for subsequent jobs to read in,
  or temporarily waiting to be transferred off the system to long-term storage.
  By default it has a quota of 20TB.
- `/projects/PROJECT`:
  If you require a shared directory for longer-term project resources,
  such as software builds,
  this is available on request by [contacting Support](support.md).

If you require more storage than the default quota,
this can be specified when completing the project application form.
For existing projects,
please [open a support ticket](support.md)
with an explanation of what changes you need,
and why you need them.

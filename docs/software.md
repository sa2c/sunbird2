# SUNBIRD2 software

The following software is currently available on SUNBIRD2 via modules:

Package managers:

- EasyBuild
- Spack

Compilers:

- GNU Compiler Collection:
    - 4.8.5
    - 13.5.0
    - 14.4.0
    - 15.3.0
- AOCC
    - 5.2
- Intel
    - 2026.1
- NVIDIA CUDA
    - 13.0.3
  
MPI libraries:

- Intel MPI 2021.18
- Open MPI 4.1.8
- Open MPI 5.0.10

Languages:

- R (via rig)
- Go
- Java
- Miniconda

Build tools:

- CMake

Additionally,
the following tools are always available at the command line:

- Apptainer
- curl
- dos2unix/unix2dos
- emacs
- git
- htop
- lstopo
- nano
- numactl, numastat, taskset
- OpenSSL (including OpenSSL-devel)
- perl
- pinky
- screen
- tar, xz, zstd
- tmux
- vim
- wget
- zip
- zsh

If a piece of software you wish to use is not available,
in the first instance we would encourage you to install it in your home directory.
If this is not possible,
or you need software that will be used by many people as a module,
please complete [the software request form](https://forms.cloud.microsoft/e/DCaZU8amCF).
